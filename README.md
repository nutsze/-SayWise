# Grasp

Настольное приложение для изучения английского языка для русскоязычных: 12 ступеней
от **A1.1 до C2.2** и подготовка к **TOEFL iBT** (формат с 21 января 2026).

Не «очередной Duolingo»: явная грамматика на русском, темы целиком (все 12 времён в
одном модуле), продукция вместо угадывания, журнал ошибок и интервальное повторение,
умеренная геймификация без давления стриками.

> **Версия 0.1 — каркас (шаг 1 из 8).** Окно, навигация, темы, F11, High DPI,
> встроенные шрифты, настройки, БД с миграциями, сборка EXE/установщика и автотесты
> отображения. Учебные модули, тесты и TOEFL-задания — в следующих версиях.

## Запуск из исходников

Нужен Python 3.12+.

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows (Linux/macOS: source .venv/bin/activate)
pip install -r requirements-dev.txt
python -m grasp
```

## Сборка Grasp.exe, установщика и портативной версии

Windows 10/11 x64, Python 3.12+, [Inno Setup 6](https://jrsoftware.org/isinfo.php)
(`winget install JRSoftware.InnoSetup`). Одной командой:

```bat
build.bat
```

`build.bat` создаёт `.venv`, ставит зависимости и вызывает `build.py`:

1. **тесты** — pytest, включая матрицу отображения и проверку глифов;
2. **Grasp.exe** — PyInstaller, режим *onedir* (`build/pyinstaller/Grasp/`), без консоли,
   с иконкой 16…256 px, версией и издателем в свойствах файла;
3. **smoke-test сборки** — `Grasp.exe --smoke-test` открывает все экраны, переключает
   темы и F11 и записывает результат в JSON;
4. **GraspSetup-0.1.0.exe** — Inno Setup: Program Files, ярлыки на рабочем столе и в «Пуске»,
   пункт в «Приложения и возможности», при удалении — вопрос, стирать ли прогресс;
5. **Grasp-0.1.0-portable-win64.zip** — распаковать куда угодно и запустить.

Результат — в `dist/`. Флаги: `--skip-ui-matrix`, `--skip-tests`, `--skip-installer`, `--skip-zip`.

CI (`.github/workflows/build-windows.yml`) делает то же самое на `windows-latest`,
затем тихо устанавливает GraspSetup.exe, запускает установленный Grasp.exe **без Python
в PATH**, проверяет, что данные пишутся в `%APPDATA%\Grasp`, и удаляет программу.
Для тега `v*` собранные файлы прикрепляются к релизу GitHub.

## Где что хранится

| Что | Где |
|---|---|
| Программа | `C:\Program Files\Grasp\` (установщик) или любая папка (zip) |
| Прогресс (SQLite), настройки, записи голоса, модели речи | `%APPDATA%\Grasp\` |
| Логи | `%APPDATA%\Grasp\logs\` |
| Портативная версия | `GraspData\` рядом с `Grasp.exe` (есть `portable.flag`) |
| API-ключ LLM | Диспетчер учётных данных Windows (keyring), не в файлах |

Модель faster-whisper в установщик не входит: она скачивается по кнопке в настройках
(≈145 МБ base / ≈484 МБ small) в `%APPDATA%\Grasp\models`.

## Структура проекта

```
grasp/
  app.py               запуск: High DPI, один экземпляр, шрифты, тема, БД, окно, --smoke-test
  paths.py             resource_path() (исходники и _MEIPASS) и user_data_dir() (%APPDATA%\Grasp)
  core/                логика без виджетов
    levels.py            12 подуровней, сравнение, шкала TOEFL 1–6
    content.py           загрузка контента, проверка поля level, «По темам» / «По уровням»
    settings.py          settings.json (тема, шрифт, окно, цель, дата экзамена…)
    secrets.py           API-ключ через keyring
    single_instance.py   один экземпляр: повторный запуск разворачивает окно
    crash.py             перехват исключений → окно «Что-то пошло не так»
    logging_setup.py     логи + faulthandler в %APPDATA%\Grasp\logs
    model_download.py    загрузка модели faster-whisper с прогрессом и отменой
  data/                SQLAlchemy-модели, подключение, миграции Alembic (выполняются при старте)
  ui/                  PySide6
    theme.py             светлая / тёмная / системная; QSS только из токенов темы
    main_window.py       навигация, F11/Esc, Ctrl +/−/0, Ctrl+1…7, геометрия окна
    pages/               экраны: Главная, Грамматика, Повторение, Журнал ошибок, TOEFL, Словарь, Настройки
    widgets/             Page (колонка ≤ ~80 символов + боковая панель), FlowLayout, таблицы
  content/             учебный контент (JSON, у каждой единицы есть level)
  resources/           шрифты Noto (OFL), SVG-иконки, app.ico, темы
tests/                 pytest + pytest-qt; ui_audit.py — матрица отображения
tools/                 check_glyphs.py (покрытие глифов), make_icon.py (app.svg → app.ico)
installer/grasp.iss    Inno Setup
grasp.spec, build.py, build.bat
```

## Тесты

```bash
pytest                              # всё, включая матрицу отображения (~1–2 мин)
GRASP_SKIP_UI_MATRIX=1 pytest       # без матрицы
python tools/check_glyphs.py        # каких символов контента/интерфейса нет в шрифтах
```

**Матрица отображения** (`tests/ui_audit.py`): каждый экран × 1280×720, 1920×1080,
2560×1440, 3840×2160 × масштаб 100/150/200 % × светлая/тёмная тема (+ шрифт приложения
150/200 %). Для каждого состояния сохраняется скриншот в `build/ui-screens/` и
автоматически ищется обрезанный текст: размер виджета сравнивается с `sizeHint()` /
`heightForWidth()`, самое длинное неразрывное слово — с шириной метки, геометрия — с
родителем, высота строк таблиц — с высотой текста.

Также проверяются: контраст WCAG AA (≥ 4.5:1) для всех пар цветов обеих тем, включая
цвета ошибок и правильных ответов; отсутствие захардкоженных цветов в виджетах;
соответствие миграций Alembic моделям; размеры в app.ico.

## Ручная проверка на чистой Windows (Windows Sandbox / ВМ без Python)

- [ ] GraspSetup.exe ставится, ярлыки на рабочем столе и в «Пуске» с иконкой Grasp
- [ ] Двойной клик — запуск без консольного окна; повторный запуск разворачивает уже открытое окно
- [ ] F11 — полный экран, Esc — выход; размер/положение/режим окна восстанавливаются после перезапуска
- [ ] 4K и масштаб 150–250 %: чёткие иконки и текст, ничего не обрезано
- [ ] Тёмная/светлая/системная тема переключаются на лету
- [ ] Ctrl + / Ctrl − / Ctrl 0 меняют размер шрифта
- [ ] Прогресс и настройки сохраняются после перезапуска (`%APPDATA%\Grasp`)
- [ ] Без интернета приложение запускается и работает
- [ ] Удаление через «Приложения и возможности»; вопрос об удалении прогресса
